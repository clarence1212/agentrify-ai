A-RSI framework

Self-improvement that is safe because it is scoped.

A-RSI, application-scoped recursive self-improvement, is the engineering behind Agentrify's Evolve layer. The loop may change only a declared set of components, is scored only by an evaluator it cannot touch, and is promoted only through a governor that is code rather than a model. Safety and application-specificity are the same design move.

Layer 1

Three bands, one return path.

A candidate change originates in the periphery, is scored in the frozen core, passes the governance gates, and is written back only through the governor. Nothing in the loop can touch the middle band.

Layer 2

Separation of duties, enforced in code.

Multi-agent supplies the separation; multi-model supplies the independence. No two of proposer, judge and critic share a model family, and the dashed barriers are typed views that raise when crossed.

Layer 3

Scoped to the application.

Each domain agent owns a slice of the surface and its own domain evaluations. One governor, one judge, one set of system-level guard metrics. A star, not a mesh: no agent can tune itself against another agent's behaviour.

Fast feedback

Scoreable within hours

The loop lives on the evaluator. If ground truth arrives in months, scope the loop to an intermediate step that has fast ground truth.

Harness-bound

Headroom in the scaffolding

A-RSI improves prompts, tools, skills, retrieval and small adapters. If the errors come from what the base model does not know, the loop finds nothing.

Volume

Enough cases to refresh held-out sets

The evaluator decays as the proposer saturates it. A steady stream of new cases, real or generated, keeps the acceptance rule honest.

Fits best: customer support, document processing, code generation, data extraction, research triage, compliance screening. Fits poorly: low-volume bespoke judgment, outcomes measured in quarters, tasks whose quality is in the model's knowledge rather than its scaffolding.

Reference stack

Runs offline, out of the box.

A small Python package where every band is a module and every rule above is enforced in code. It ships with a support-triage example and a mock model, so the whole loop can be inspected before a single API key is involved.

Six steps to a new application

  • The application and its fast-feedback check
  • The mutable surface: each file the loop may rewrite, with its change class
  • The evaluator: primary metrics with minimum effect, guard metrics with tolerance
  • Roles and model families, independence rule enforced
  • Bounds: proposals per cycle, lineage depth, cycles without a human
  • Change-class policy: autonomy earned per class; tool, adapter and topology stay human-gated

Then implement score() and failures() for your application and fill three case files. Going live is three lines of config.
